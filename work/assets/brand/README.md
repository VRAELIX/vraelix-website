# Brand assets to provide

The existing supplied VRAELIX logo remains in use until an approved replacement is added. Do not draw or substitute artwork.

Place these owner-provided files in this folder:

- `vraelix-logo.svg` **or** `vraelix-logo.png` — transparent brand logo for the footer; SVG is preferred.
- `favicon-V/` — owner-provided light/dark V-mark PNG favicons at 16, 32, 48, and 512 pixels.

These supplied favicon files are copied unchanged and wired into every generated page. No other favicon artwork is generated or substituted.
